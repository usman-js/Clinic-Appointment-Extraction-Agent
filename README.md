# W7 D2 assignment: the clinic booking form

1. Put this folder inside `w7-llm-apis`, next to `day2`.
2. Open a terminal inside this folder and activate your venv.
3. Fill in the TODOs in `schemas.py` and `extract_appointments.py`.
4. Run it and save the output:

       python extract_appointments.py > results.txt

5. Fill in `answers.md`.

Never put your `.env` file in your submission. It contains your API key.
